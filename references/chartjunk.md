# chartjunk 顶刊红线 · geo-figure-studio

出草图前自检；用户说"感觉不好看"时逐条对照。每条给「错误 → 正确」。

## 图表类型

- **3D 饼图** → 改 2D 条形图或堆叠条形图。3D 饼图面积被透视扭曲，无法比较。
- **3D 柱状/曲面**（无真实第三维信息时）→ 改 2D + 颜色编码。

## 视觉装饰

- **渐变背景 / 花哨底色** → 纯白底。任何非数据墨水都要删。
- **阴影、发光、倒影** → 删。期刊一律不接受。
- **高饱和荧光色**（#00FF00 荧光绿、品红）→ 用 `TOL_MUTED` 或 `PALETTES` 里的低饱和色。
- **无意义的网格线** → 只留主轴刻度，或全部去掉；需要对齐时用浅灰细虚线。

## 坐标与比例

- **双 Y 轴滥用**（两种量纲硬塞同一面板）→ 拆成上下两个共享 X 轴的子图，或归一化后合并。
- **截断的 Y 轴**（不从 0 开始且无标记）→ 若截断必须加断裂标记 `//`，并说明为何截断；
  默认从 0 开始。
- **坐标轴无单位/量纲** → 每个数值轴都写清楚单位（`NDVI`、`m`、`°C`、`%`）。

## 图例与文字

- **图例遮挡数据** → 移到空白区；地图类可放到图外右侧，或改白底半透明。
- **字号 < 5pt** → 印刷后无法辨认。期刊正文图最小 6pt，一般 7-8pt。
- **有效数字过多**（`0.384728193`）→ 按参数 `significant_digits`（默认 2）舍入。
- **子图编号位置不一致** → 全部统一放左上角 `(a)(b)(c)`，字号 9-10pt、加粗。

## 地图类专属

- **缺比例尺** → 地图必须有（原理示意图除外，且须标"示意图"）。
- **缺指北针** → 同上。
- **缺经纬度标注** → 加经纬网/边框刻度，并标投影（如 `CGCS2000 / 3-degree GK zone 40`）。
- **色带无单位** → colorbar 顶部或标签写单位与指数（如 `NDVI`、`LST (°C)`）。
- **nodata 被当成 0** → `make_fig.py` 用 `masked(arr, nodata=...)` 把 nodata 置 NaN，
  否则均值/趋势被 0 拉低，图上出现假低值区。

## 检验口诀

一图只讲一件事；每滴墨水都为叙事服务；去掉后不影响理解的元素一律删。
