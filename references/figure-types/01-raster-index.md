# 图型 01 · 栅格指数专题图（raster-index）

NDVI / EVI / NDWI / LST / 植被覆盖度 / LAI 等**连续栅格**的专题制图。

## 适用数据

- 单波段或单时相的栅格指数（GeoTIFF 等）
- 经预处理后的指数产品（合成、云掩膜、大气校正——口径见硬门禁第 3 项）

## 必须要素

1. **地图底**：研究区边界 + 行政边界（省界实线、市界虚线）+ 海岸线/水体
2. **指数色带**：连续色带（顺序或发散，见 `palettes.md`）
3. **colorbar**：右侧竖条，顶部写指数名与量纲（如 `NDVI`、`LST (°C)`）
4. **比例尺** + **指北针** + **经纬网**（边框刻度）
5. **投影标注**：右下角或图注，如 `CGCS2000 / 3-degree GK zone 40`
6. **nodata 处理**：`masked(arr, nodata=...)` 置 NaN，白色/灰色显示，不参与分级

## 常见坑

| 坑 | 现象 | 修 |
|----|------|-----|
| nodata 当 0 | 均值/趋势被 0 拉低，图边出现假低值带 | `masked(..., nodata=...)` |
| 色带方向反 | 高值低值色感与直觉相反（植被应用绿=高） | 检查色带是否需要 `_r` |
| 分级脱离分布 | 出现空级或全挤一级 | 先画直方图再定断点，Jenks/分位数优先 |
| 无投影 | 经纬线弯、面积失真 | 硬门禁第 7 项定投影，`cartopy` 设 `crs` |
| colorbar 无量纲 | 读者不知道数是什么 | colorbar 标签写指数名+单位 |

## 顶刊默认（草图阶段先按此出）

- 色带：NDVI→`YlGn`；LST→`YlOrRd`；距平→`RdYlBu_r`
- 分级：`quantile` k=5 或 `jenks` k=5；断点取整
- 色盲校验：连续色带 k≤6（见 `palettes.md` 实测表）
- 图例字号 7pt、colorbar 标签 8pt

## 叙事检验

一张 NDVI 图要能一眼回答：**哪里绿、哪里秃、差异多大、为什么是这个分布**。
答不出，说明分级/配色/图例还没讲清楚，回精修区块 A。
