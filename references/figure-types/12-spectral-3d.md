# 图型 12 · 光谱曲线与三维地形图（spectral curves / 3D terrain）

地物光谱反射率曲线（可分性分析）与 DEM 三维可视化。

## 适用数据

- 光谱曲线：多/高光谱数据，波长 vs 反射率
- 三维地形：DEM + 叠加纹理（影像/指数），或纯高程

## 必须要素

### 光谱曲线

1. **横轴波长**（nm/μm）+ **纵轴反射率**（无量纲 0–1 或 %），两者都写清
2. **多曲线对比**：不同地物分色 + 图例，或均值±标准差阴影带
3. **波段标注**：关键波段（可见光/近红外/短波红外）位置可标

### 三维地形

1. **视角与光照**：明确观察方位角/高度角；有光照和阴影
2. **垂直夸大**：必须标注垂直夸大倍数（如 `垂直夸大 2×`），不标就是误导
3. **色带**：高程 `terrain` 或叠加纹理
4. **坐标**：三维图上仍可读经纬度/距离

## 常见坑

| 坑 | 现象 | 修 |
|----|------|-----|
| 光谱曲线无波长标注 | 不知横轴是什么 | 标波长 + 单位 |
| 曲线重叠难分 | 无法比较地物 | 分色 + 图例，或分面绘制 |
| 三维无垂直夸大说明 | 地形被严重误导 | 明确标夸大倍数 |
| 视角刁钻 | 关键地形被遮挡 | 选能展示主格局的视角 |
| 无光照阴影 | 立体感缺失 | 加光源 |

## 顶刊默认（草图阶段）

- 光谱曲线：地物用 `TOL_MUTED` 分色，线宽 1pt；均值±std 用透明带
- 三维地形：azimuth 315°、altitude 45°、垂直夸大 1–3× 并标注
- 色带：`terrain` 或叠加影像

## 叙事检验

光谱曲线回答"**不同地物光谱可分性**（哪个波段可分、可分度多少）"；
三维地形回答"**地形格局的立体直观**（山体走向、河谷形态、高差）"。
两者都是"让不可见的结构可见"。
