# 图型 06 · 局部放大图（inset / zoom map）

主图展示全局格局，放大图展示某个关键局部的高分辨率细节。

## 适用数据

- 主图数据（全局）+ 局部更高分辨率/更详细数据（如某城市、某流域出口）

## 必须要素

1. **放大框**：主图上用醒色框标出被放大区域
2. **连线**：放大框与放大图之间用细线/箭头关联
3. **各自比例尺**：主图和放大图各一个（尺度不同，必须分别标）
4. **放大图边界**：放大图加边框，与主图视觉区分
5. **投影一致**：主图与放大图同投影，避免形状错位

## 常见坑

| 坑 | 现象 | 修 |
|----|------|-----|
| 放大框位置不标 | 读者不知道放大的是哪 | 主图上画醒色框 |
| 连线缺失 | 两张图关系不明 | 用连线关联 |
| 无各自比例尺 | 放大倍数不明 | 两个面板分别标 |
| 主图与放大图投影不同 | 边界对不上 | 统一投影 |
| 放大图信息密度不足 | 放大了也没细节 | 换更高分辨率数据或加要素 |

## 顶刊默认（草图阶段）

- 放大框：1pt 红色/橙色实线框，主图右下或左下
- 放大图：放主图角落或右侧，加边框
- 连线：细黑线 + 小箭头

## 叙事检验

主图回答"整体格局"，放大图回答"关键局部细节"，两者协同讲清一个空间故事。
放大图若没有新信息，就不该放大。
