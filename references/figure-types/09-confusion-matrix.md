# 图型 09 · 混淆矩阵图（confusion matrix）

分类结果 vs 验证样本的类别交叉表，展示分类精度与混淆来源。

## 适用数据

- 分类结果 + 独立验证样本的类别标签对（n×n 交叉表）

## 必须要素

1. **矩阵热力**：数值用离散/顺序色带映射，主对角线深色高亮
2. **类别名**：行=预测类、列=参考类（或反之），写**真实类别名**而非 0/1/2
3. **每格双值**：样本数 + 百分比（或 UA/PA）
4. **精度指标**：OA（总体精度）、Kappa 标在矩阵外；UA/PA 可标行末/列末
5. **坐标轴标签**：明确写"预测类别"/"参考类别"

## 常见坑

| 坑 | 现象 | 修 |
|----|------|-----|
| 只有数字无类别名 | 看不懂是哪类 | 行列写真实类别名 |
| 主对角线不高亮 | 分不清对错 | 对角线深色、非对角浅色 |
| 缺 OA/Kappa | 无法总评精度 | 矩阵外标注 |
| 用连续色带 | 把类别当大小 | 用离散色带映射混淆强度 |
| 训练/验证不分 | 精度虚高 | 用独立验证样本 |

## 顶刊默认（草图阶段）

- 色带：主对角线 `Blues` 深色，非对角线浅灰/白；混淆越重越深
- 每格：`样本数\n(%)`；行末标 UA，列末标 PA
- 字号 7pt，类别名可 45° 斜排（类别名长时）

## 叙事检验

一眼看出：**哪些类分得准、哪些两类互相混淆（如建成区↔裸土）、总体精度几何**。
混淆矩阵的价值在"错在哪"，不在"总数多少"。
