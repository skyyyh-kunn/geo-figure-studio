# 图型 10 · 多面板统计图（multipanel-stats）

多个统计子图拼成一幅：散点/回归、箱线、直方、误差棒、时间序列、混淆矩阵等的组合面板。
常见于"结果分析"章节：一个图讲清一个量化结论的多侧面。

## 面板类型速查

| 面板 | 适用 | 要点 |
|------|------|------|
| 散点+回归 | 两变量关系 | 标 R²、p、样本量 n |
| 箱线/小提琴 | 分组分布对比 | 标显著性（*、**、ns） |
| 误差棒柱状 | 均值±误差 | 误差棒要写±SD 还是±SE |
| 时间序列 | 趋势/周期 | 时间轴刻度取整年 |
| 混淆矩阵 | 分类精度 | 行列写类别名，主对角线高亮 |
| 直方/密度 | 分布形态 | 透明填充+边框，防重叠 |

## 必须要素

1. **子图编号**：`(a)(b)(c)` 左上角，9–10pt 加粗，全图位置统一
2. **每面板完整轴**：坐标轴标签+单位+刻度；共享轴时才省略重复标签
3. **统计量标注**：R²、p、n、显著性——论文统计图不能只给图不给数
4. **统一风格**：所有面板同字体、同字号、同线宽、同配色（跨面板色带一致，见精修 A）
5. **图例**：只在首面板或有图例的面板给一次，避免每面板重复

## 常见坑

| 坑 | 现象 | 修 |
|----|------|-----|
| 面板对齐错位 | 轴标签长短不一时图乱 | `constrained_layout` 或 `GridSpec` + `fig.align_labels()` |
| 显著性只画星没检验 | 编造显著性 | 必须跑真实检验，报告方法与 p 值 |
| 误差棒含义不明 | 读者不知是 SD 还是 SE | 图注写 `±SD` 或 `±SE` |
| 时间轴刻度乱 | 年份 2018.5 这种 | 主轴刻度取整年 |
| 散点图无数 | 有趋势线没 R²/p/n | 必标统计量 |
| 混淆矩阵无类别名 | 只有 0/1/2 | 行/列写真实类别名 |

## 顶刊默认（草图阶段）

- 字号：轴标签 8pt、刻度 7pt；子图编号 10pt 加粗
- 配色：定性用 `TOL_MUTED`；连续用 `viridis`/`RdYlBu_r`
- 布局：2×2 或 2×3；间距用 `wspace=0.25, hspace=0.3` 起调
- 数据点：散点 `s=8`、`alpha=0.6`，回归线粗 1pt 实线

## 叙事检验

多面板图的价值在**对比与综合**：面板之间要么对比（不同分组/区域），要么递进
（分布→关系→趋势）。如果面板之间没有逻辑关系，拆成多张单图更诚实。
