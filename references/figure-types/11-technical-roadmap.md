# 图型 11 · 技术路线图（technical roadmap）

纯示意流程图，展示研究从数据到结论的完整链路。**不依赖地理数据**。

## 适用数据

- 无数据（流程/方法示意），用 matplotlib 的矩形+箭头+文本绘制

## 必须要素

1. **主线单向**：数据 → 预处理 → 方法 → 结果 → 结论，箭头单一方向
2. **分层分阶段**：按"数据层/方法层/结果层/应用层"分层，或按步骤分阶段
3. **方法标注**：关键方法/模型/软件/参数标在框内或旁注
4. **图例统一**：不同颜色代表不同性质（数据/方法/结果），图例说明
5. **箭头逻辑**：箭头只表示流向，不交叉、不回头

## 常见坑

| 坑 | 现象 | 修 |
|----|------|-----|
| 箭头乱指 | 流程读不通 | 主线单向，箭头从数据指向结论 |
| 层级不分 | 数据与方法混在一起 | 分层/分阶段布局 |
| 文字堆砌 | 框里塞满长句 | 短语化，细节放旁注 |
| 颜色过多 | 花哨抢戏 | 2–3 色 + 灰度 |
| 用软件截图 | 分辨率低、风格不统一 | 矢量重绘 |

## 顶刊默认（草图阶段）

- 布局：纵向分层（顶层数据→底层结论）或横向分阶段
- 框：圆角矩形，1pt 边框；箭头：单向实线
- 颜色：数据=浅蓝、方法=浅灰、结果=浅绿，图例在角落

## 叙事检验

读者不看正文就能**复述整个研究流程**：用了什么数据、做了什么处理、用什么方法、得到什么结果。
路线图是"研究的目录"，不是装饰画。
