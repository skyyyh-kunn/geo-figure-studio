# 图型 03 · 矢量分级设色图（vector choropleth）

面状矢量（行政单元/流域/网格）的属性分级设色，如人口密度、GDP 密度、某项比率。

## 适用数据

- 面状矢量 + 属性表（shp/geojson/gpkg）
- 属性是**比率/密度/均值**（非绝对数，避免面积偏差）

## 必须要素

1. **分级设色**：`classify(values, method, k)` 做分级，图例标断点值
2. **单位与指标**：图例写指标名 + 单位（如 `人口密度（人/km²）`）
3. **边界线**：面边界细线（0.3pt），避免相邻同色面糊成一片
4. **比例尺 + 指北针 + 经纬网 + 投影标注**

## 常见坑

| 坑 | 现象 | 修 |
|----|------|-----|
| 用绝对数不用比率 | 大单元永远"看起来"更严重 | 换成密度/人均/占比 |
| 分级脱离分布 | 空级或全挤一级 | 先看直方图，Jenks/分位数优先 |
| 色带与主题反 | 风险用冷色、温度用红色 | 顺序/发散色带选对方向 |
| 缺归一化 | 不同图不可比 | 统一指标口径与分级边界 |
| 边界线过粗/无 | 糊成一片或抢戏 | 0.3pt 浅灰边界 |

## 顶刊默认（草图阶段）

- 分级：`jenks` k=5 或 `quantile` k=5，断点取整
- 色带：比率/密度→`YlOrRd`/`Blues`；正负指标→`RdYlBu_r`
- 边界：0.3pt、`#888888`

## 叙事检验

回答：**哪里高、哪里低、为什么是这个空间格局**（与区位/地形/政策的对应）。
只有色块没有格局解读，是一张没讲完的图。
