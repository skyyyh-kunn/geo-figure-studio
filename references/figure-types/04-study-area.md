# 图型 04 · 研究区位图（study area location map）

把研究区放到更大的地理背景里定位，通常由「大范围定位图 + 研究区放大图」2–3 个面板组成。

## 适用数据

- 研究区边界矢量 + 上级行政区划 + 基础底图（海岸线/河流/主要城市）

## 必须要素

1. **层次递进**：全国/流域 → 省/区域 → 研究区，逐级放大，读者能逐步定位
2. **放大框与连线**：大图上的研究区范围用醒色框标出，并用连线引到放大图
3. **研究区高亮**：放大图里研究区用醒目填充/描边，周边弱化
4. **比例尺 + 指北针 + 经纬网**（每个面板各自或共用一个）
5. **地名注记**：上级行政名、关键城市/水系/山脉

## 常见坑

| 坑 | 现象 | 修 |
|----|------|-----|
| 只有一张研究区图 | 读者不知道它在地球哪里 | 加定位面板 |
| 放大框不连线 | 定位图与放大图关系不明 | 用连线/同色框关联 |
| 底图过花 | 地名/路网抢戏 | 底图浅灰，研究区信息突出 |
| 比例尺缺失 | 无法感知尺度 | 每个面板必加 |
| 投影不统一 | 大图与放大图形状对不上 | 同一投影或明确标注各自投影 |

## 顶刊默认（草图阶段）

- 布局：左侧定位图（大范围）+ 右侧放大图（研究区），或上下
- 放大框：粗实线（1pt）醒目色（红/橙），连线箭头
- 底图：海岸线 + 主要河流，浅灰；研究区边界加粗

## 叙事检验

读者不看正文就能说出：**研究区在全国/流域的哪个位置、覆盖哪些行政区、大致尺度多大**。
