# 图型 02 · 分类与变化检测图（classification / change detection）

土地利用/土地覆盖分类，或两时相分类结果的变化检测。

## 适用数据

- 多分类栅格（LULC、地物类型、生态功能区划）
- 两期分类结果的对比（变化检测、转移矩阵的空间化）

## 必须要素

1. **离散色带**：定性色带，每类一个语义色块（水=蓝、植被=绿、城市=红/灰、裸土=棕）
2. **类别图例**：每类一行（色块 + 类别名 + 可选面积占比），绝不混用连续 colorbar
3. **时相一致**：多时相对比必须用**同一套色带同一套图例**，否则读者无法对比
4. **比例尺 + 指北针 + 经纬网 + 投影标注**
5. **变化检测**：单独一张"变化图"（哪类→哪类），或附转移矩阵

## 常见坑

| 坑 | 现象 | 修 |
|----|------|-----|
| 连续色带表达类别 | 类别间被误读为大小关系 | 用离散色带 + 类别图例 |
| 类别颜色反语义 | 水用红色、植被用蓝色 | 遵循语义色（水蓝/植被绿） |
| 时相图例不一致 | 两期图没法对比 | 强制同一图例同一边界 |
| 类别过多 | 色盲下相邻类混 | 类别 >7 时合并相近类或换 tol_muted |
| 变化图不标"从哪到哪" | 只看出一片变化 | 变化图例写成 `A→B` 形式 |

## 顶刊默认（草图阶段）

- 色带：地类用语义色（水 `#4FA3C7`、植被 `#7DAE5B`、城市 `#C0392B`、裸土 `#B89B72`）或 `TOL_MUTED` 前 N 色
- 图例：每类一行，字号 7pt，放图外右侧
- 变化检测：变化类用暖色突出，未变化用灰

## 叙事检验

一眼看出：**什么地类占主导、分布在哪儿、两期之间什么变成了什么、变化集中在哪里**。
看不出"从哪到哪"的变化图等于没画。
