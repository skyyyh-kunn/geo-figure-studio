# 图型 07 · 样线剖面图（transect profile）

沿一条样线提取 DEM/指数/温度的变化，画出剖面曲线，配合样线位置小图。

## 适用数据

- 样线（矢量线）+ 栅格（DEM/NDVI/LST/降水），用 `rasterio` 沿样线采样

## 必须要素

1. **样线位置小图**：小图标出样线走向与起止点（A→B）
2. **剖面主图**：横轴=沿样线距离（km），纵轴=变量值+单位
3. **关键地物标注**：河流、山脊、谷地、城市等在剖面线上标注
4. **起止方向**：样线两端标 A/B，剖面横轴与之对应

## 常见坑

| 坑 | 现象 | 修 |
|----|------|-----|
| 样线位置不标 | 读者不知道剖面切在哪 | 加位置小图 |
| 横轴用经纬度 | 距离失真，不好读 | 换算成沿样线距离（km） |
| 剖面过度平滑 | 丢失真实起伏 | 用原始分辨率采样，不强行平滑 |
| 无方向 | A/B 两端不明 | 标注起止方向 |
| 纵轴无单位 | 不知变量是什么 | 标变量名+单位 |

## 顶刊默认（草图阶段）

- 布局：上剖面（主）+ 下位置（辅），或左位置右剖面
- 剖面线：1pt 实线；DEM 剖面可加填充色
- 横轴：距离 km，取整刻度；纵轴：变量+单位

## 叙事检验

回答：**沿这条线，变量如何随地形/距离/城市化梯度变化，转折点对应什么地物**。
剖面是"沿线的故事"，不是一条孤零零的曲线。
