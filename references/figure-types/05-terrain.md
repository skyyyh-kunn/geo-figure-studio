# 图型 05 · 地形晕渲图（terrain / hillshade）

DEM 制图：地形晕渲、海拔分层设色、山体阴影、坡度/坡向、地形剖面（衍生）。

## 适用数据

- SRTM / ASTER GDEM / ALOS AW3D30 等 DEM 栅格
- 坡度、坡向、地形起伏度等 DEM 派生量

## 核心技法

1. **晕渲（hillshade）**：`azimuth=315°`（西北光源）、`altitude=45°` 是制图惯例；
   光源从西北来，山脊高亮东南坡、阴影西北坡，符合人眼阅读习惯。
2. **分层设色 + 晕渲叠加**：先画 `terrain` 色带的海拔，再把 hillshade 以
   `alpha=0.35–0.5` 叠加，产生立体感又不淹没色彩。
3. **等高线**：关键海拔（如 100m/500m/1000m）加细等高线，标注高程值。
4. **colorbar**：海拔单位 `m`，色带 `terrain`（棕-绿-白-高海拔）。

## 必须要素

- 晕渲 + 分层设色（两者叠加，不可只有其一）
- 比例尺、指北针、经纬网、投影标注
- colorbar（海拔 m）
- 山顶点/重要地名（可选，视叙事）

## 常见坑

| 坑 | 现象 | 修 |
|----|------|-----|
| 光源方向反 | 山体看起来"凹"进去 | azimuth=315、altitude=45 |
| 晕渲淹没色彩 | 图发灰、看不清分级 | alpha 降到 0.35–0.5 |
| 色带选错 | 地形用 viridis 显得怪异 | 用 `terrain` 或自定义棕绿 |
| 平地对比弱 | 平原区一片同色 | 局部重采样/加等高线强化微地形 |
| 无晕渲 | 平涂色块，立体感全无 | 必加 hillshade 叠加 |

## 顶刊默认（草图阶段）

- 色带：`terrain`；分级 `quantile` k=6（再高色盲混淆，见 `palettes.md`）
- 晕渲：azimuth=315、altitude=45、alpha=0.4
- 投影：山地用 UTM / 高斯克吕格，别用地理坐标（面积/形状失真）

## 叙事检验

一张地形图要回答：**地势格局（哪高哪低）、起伏陡缓、与本文研究对象（流域/城市/植被）
的空间关系**。只有漂亮晕渲没有地理信息，是失败的装饰图。
